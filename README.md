# PGF AI Portfolio

Guofeng Pan 的 AI 技术作品集，聚焦 **计算机视觉、3D 感知、多模态 AI、机器人与边缘端部署**。

- GitHub：`https://github.com/pgf20160610`
- Portfolio：`https://pgf20160610.github.io/pgf-ai-portfolio/`

## Research Directions

- 2D 视觉 / 目标检测 / 姿态估计
- 3D 感知 / 点云 / BEV
- OCR / 文档智能
- 语音 / 音频 AI
- 多模态 / VLM / VLA
- 机器人 / ROS2 / 多传感器标定
- 边缘 AI 部署 / C++ 推理

## Engineering Stack

`C++` `Python` `OpenCV` `PyTorch` `ONNXRuntime` `MNN` `TensorRT` `RKNN` `QNN` `PCL` `ROS2`

主要部署平台包括：

`x86_64` · `Jetson Orin` · `RK3588`
